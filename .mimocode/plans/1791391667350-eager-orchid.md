# Plan — Welcome / Chat chrome redesign (UI/UX)

## Intent
Redesign the Agent Soma welcome + chat chrome as enterprise UI/UX: elegant, graphic, simple, friendly.  
**Brain status = always-on micro indicator** (not a banner). **Memory = visual aide**, not principal text.  
Merge real A0 welcome inventory (Telegram · WhatsApp · Email · RAM) with Soma single-home rules.  
**Mocks first** (existing docs only), then implement in Lit `webui/` against real APIs. No mocks/fakes in code.

## Authority
- A0 source: `~/Downloads/agent-zero-main/webui/components/welcome/*`, `sync/sync-status.html`, `plugins/_discovery/*`
- Soma IA: `docs/design/SOMA-UI-IA-001.md` · chrome: `docs/design/mockups/UI-S-00-chrome.md` · hero: `UI-S-07-chat-workspace.md`
- Real fields only: `SOMA-UI-CATALOG-001.md`

---

## 1. Design principles (this pass)

| Principle | Meaning |
|---|---|
| **Composer first** | One hero action. Everything else is secondary or ambient |
| **Status is ambient** | Brain/connection = 8–12px indicator + tooltip. Never a red banner unless broken |
| **Memory is a quiet aide** | Soft glyph / pulse / ghost chip. Not a card, not headline copy |
| **One home per feature** | Memory `/memory` · Models Settings›Models · Channels Settings›Integrations · Brain canvas |
| **Real data only** | Hide block if API down. No invented RAM, no fake recall counts |
| **Friendly geometry** | 8px radius, generous whitespace, one accent (Soma blue), muted chrome |

## 3. Reusable status indicator (brain / sync / memory)

**Pattern:** A0 `sync/sync-status.html` — single 20×20 SVG circle, color + pulse by mode.

```
 Chat top (always):     14:32   ◉   ○   ◌   🔔   ▢ Q3 Launch ▾
                         │     │   │   │
                         │     │   │   └── Memory aide (soft pulse when LTM ready)
                         │     │   └────── Sync / WS (same circle language)
```

### 3.1 Brain connector micro-indicator

| State | Visual | Tooltip (hover / aria-label) |
|---|---|---|
| Healthy | Filled circle `#00c340` r=6 | `Brain · Connected` |
| Degraded | Filled `#ff6b00` + soft pulse | `Brain · Degraded` |
| Handshake | Amber ring `pendingPulse` | `Brain · Connecting…` |
| Disconnected | Red stroke ring `#e40138` | `Brain · Disconnected` |
| Unknown | Grey hollow | `Brain · Status unavailable` |

- **Size:** 12px in chat top. Never grows into a banner.
- **Click:** opens Brain surface (UI-X-07) or Settings›Connectivity — one home.
- **Data:** `GET /core/brain-connector` (existing poll in `soma-chat.ts`).
- **Accessibility:** `role="img"` + `aria-label` matching tooltip.

### 3.2 Memory aide (not principal text)

| Placement | Visual | Behavior |

| In-thread C2 | Ghost chip `recall 3` (existing) | Link to `/memory?turn=current` only |

**Never:** “Memory context” as hero copy · memory dashboard on welcome · count spam.
