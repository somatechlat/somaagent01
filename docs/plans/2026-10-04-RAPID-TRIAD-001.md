### Rules every agent is fed

1. **NO HARDCODED VALUES.** A default IS one. The two post-edit greps must return nothing.
2. **NO FALLBACKS.** A value comes from a real setting or the call **refuses**.
3. **SETTINGS CHAIN — one:** `Capsule > AgentSetting > InfrastructureConfig > SettingsModel > EMPTY`. ENV = bootstrap only, each required, never defaulted: `SA01_DEPLOYMENT_MODE`, `VAULT_ADDR`, `VAULT_TOKEN_FILE`, `POSTGRES_HOST`, `POSTGRES_PORT`.
4. **NO STUBS/MOCKS/SHIMS/TODOs.** A shim is a bypass. Fix the consumer.
5. **SECRETS — Vault only.** KV v2 `POST` replaces the document: read → merge → write full object → **read back and assert**. Never write a secret to any file including `/tmp`.
6. **FAIL-CLOSED (Rule 91).** A missing value is a refusal naming the setting.
7. **NEVER WEAKEN A GATE TO PASS A TEST.**
8. **CHECK FIRST, CODE SECOND.**
9. **NO UNNECESSARY FILES.** Delete, do not back up.
10. **DOCUMENTATION = TRUTH.**
11. **COMMITS** under the user's own identity. **No AI attribution of any kind.**
12. **DESIGN CRITERIA:** the rules · millions of transactions · security · speed · latency · thin.
